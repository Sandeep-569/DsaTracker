ENGINEERING HIGHLIGHTS
🤖

Automated Cron Pipeline

Scheduled GitHub Actions worker fetches recent accepted solves via LeetCode GraphQL, matches them to problem slugs, and automatically updates Firestore via the Firebase Admin SDK with zero manual input.

🔒

Multi-Tenant Cloud Security

Fine-grained Cloud Firestore Security Rules enforce strict per-user boundaries (users/{uid}). Each authenticated user has their own private cloud document that cannot be accessed or modified by others.

⚡

Optimistic Real-Time Sync

Powered by Firestore onSnapshot listeners with bidirectional synchronization, debounced writes, and immediate local caching for sub-millisecond perceived latency across desktop and mobile.

📊

Intelligent Search & Analytics

Multi-token fuzzy search supporting problem names, company tags, and LeetCode IDs. Includes a GitHub-style 53-week interactive contribution heatmap tracking daily solving consistency.
